# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues or
discussions.

Report vulnerabilities privately through GitHub Security Advisories:

<https://github.com/betocmn/preseason/security/advisories/new>

Include clear reproduction steps, expected impact, and any mitigations you
already tested.

## What to Expect

We aim to:

- Acknowledge receipt within 72 hours.
- Provide an initial triage update within 7 days.
- Ship a fix (or mitigation plan) for confirmed high-severity issues within 30
  days when feasible.

Response timelines can vary based on maintainer availability and issue
complexity, but private reporters will be kept informed throughout triage and
remediation.
